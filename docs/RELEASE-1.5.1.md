# 拾影 1.5.1 发布说明

本版基于已实机验收的 1.5 一体化版本，修复 macOS 取消任务时终止信号被子进程继承屏蔽的问题。保留 Windows x64 安装器、Mac Apple Silicon App，以及全部已有下载、OCR 和转写依赖。

## 改动

- 父进程注册子进程期间仍屏蔽终止信号，避免取消时漏掉刚创建的任务；子进程通过隔离的 Python 启动中转清除屏蔽，再执行内核。
- 不使用 Python `preexec_fn` 回调；启动中转显式使用 `-B`，防止缓存写入 App 破坏签名。
- 新增真实子进程及孙进程的 SIGTERM 处理测试，强制终止不能算该测试通过。旧实现的变异测试会超时失败。
- App 取消回归改为载入实际构建包里的 runner，并检查取消延迟和子进程退出。
- 新增模块纳入主源码 / App 快照哈希检查，两个平台保持相同源码。

问题分析参考 Claude 会话及其提交 b97e6cd；本次采用独立启动中转实现，没有整体覆盖 Claude 的运行时方案。已有链接解析修复保留。

## 验证

- Mac 完整重建，Swift 编译通过；源码与快照、包内 runner 和关键内核逐字节一致，版本为 1.5.1。
- 所有回归脚本及 Swift 链接解析测试通过；App 包内取消测试通过，取消无需等满 3 秒强杀宽限期，子进程不残留。
- 包内 Python + 包内进程模块的真实父子进程测试通过，约 0.004 秒响应 SIGTERM，两个进程都执行了正常退出处理；撤掉修复测试超时失败。
- 新 HOME、限制 PATH 后，实际包内识别依赖导入、工具启动、本地视频导入与全片解码通过，无需 ~/.vx。
- 实际运行后，Mach-O 外部绝对依赖审计及 `codesign --verify --deep --strict` 通过。
- [Windows GitHub Actions 34433965008](https://github.com/bhx52222/Video_download/actions/runs/34433965008) 构建、实际安装、包内依赖、中文路径导入、全片解码、OCR 与 GUI 启动通过。
- Windows 11 ARM64 虚拟机：本版 EXE 安装到独立目录，退出码 0；未另外配置开发环境，依赖导入、包内 FFmpeg、中文路径导入、全片解码、实际 OCR、GUI 进程启动均通过。
- Windows 英文转写真实推理复测通过，识别出完整测试语句，约 11.5 秒；使用已有模型缓存并启用离线模式，不算首次模型下载测试。

## 使用及限制

见 [安装说明](INSTALL-1.5.1.md)。无需另外安装 Python、FFmpeg 或配置 ~/.vx；转写模型首次使用联网下载。

- macOS 14+、Apple Silicon；Windows x64 安装包，Windows 11 ARM64 通过 x64 兼容层运行。
- 当前为公开测试版，Mac 本地签名未公证；Windows 未进行发布者签名。
- Downie 4 / IDM 需用户自行安装授权，未打包；IDM 真实联动仍未验收。
- 视频号无链接卡片采集、真实中文转写和全平台完整回归仍未完成。
- 1.5 的英文转写及指定快手样本实测记录见 [历史验收](STANDALONE-1.5.md)，不等同于本版重测或全平台保证。
- 本版不修改代理、系统证书、登录态或用户媒体库。当前 Windows VM 存在旧系统代理地址，本地安装测试不据此声称联网下载全部可用。
