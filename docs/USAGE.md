# 使用说明

## 输入与下载

粘贴单作品链接或带链接的分享文字，每行一条。首页、推荐流和作者主页不是确定的单条视频。添加本地视频也可进行转写与 OCR。

仅下载会保存媒体并检查有效性，不运行语音识别或 OCR。之后可对同一作品继续转写。结果按作品分目录，包含 `meta.json`、`media/` 及按所选模式生成的字幕、截图、报告。

“重新处理”不会自动重下媒体；“重新下载媒体”将旧文件移到 `media/_replaced/`。旧派生字幕、报告可能保存在 `notes/_superseded/`，便于恢复。

## 画质与登录

内核一般默认最高 1080p；快手页面直链与 Downie 使用各自画质，不受此上限控制。部分编码无法直接由 QuickTime 播放。

浏览器选择“不使用”时不读取浏览器 Cookie。需要登录的作品可选择已登录的浏览器；抖音的“新鲜 Cookie”提示也可能出现在已登录状态。小红书分享令牌会过期，请复制完整的新链接。登录态留在本机，不随源码发布。

## YouTube 与 Downie 4

可选内核下载、失败后使用 Downie 4、直接使用 Downie 4。电脑必须安装 Downie 4 并关联 `downie://` 协议；同时装有 Downie 3 时需核对关联。

只有独立任务目录中出现稳定且有效的视频，并完成校验归档，才算成功。发送请求不等于下载完成。画质或字幕弹窗由 Downie 控制；单条等待最多 10 分钟。取消拾影不会取消 Downie 中的下载，超时后可手动导入已下载的视频。

## 视频号

分享链接：输入 `https://weixin.qq.com/sph/…`，可能需要 Edge 或 Chrome 的元宝登录态。

只有卡片：打开“视频号采集”试验窗口，查看本机 API 服务和页面连接状态，再查看最近观看记录。默认 API 为 127.0.0.1:2022。仅启动服务不会自动把微信页面接入；未连接时不能凭空由 objectId 生成链接。

App 启动的连接组件明确关闭自动代理、TUN、证书安装和远程桥接。不要把“服务已启动”当成采集已成功。真实卡片链路仍待验证，当前发布包不承诺此能力已可用。

## 转写与 OCR

安装包已包含语音识别依赖，模型首次使用会下载。静音视频、无效 OCR 和零散文字不会记为“互校完成”。所有自动文字都可能出错，需结合原视频核对。

## Windows 的 IDM 备用

Windows 可选内核下载、失败后用 IDM、直接用 IDM。IDM 需自行安装授权；拾影先解析可用的单文件媒体地址，再交接、等待有效文件并归档。解析失败不保证能被 IDM 补救。取消拾影不会取消 IDM 自身的下载。真实 IDM 联动仍未验收。
