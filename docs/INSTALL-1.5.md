# 拾影 1.5 一体化安装包

此说明对应 1.5 独立包开发分支；1.4.1 旧版仍依赖外部环境，不能混用安装说明。最终验收状态见 `STANDALONE-1.5.md`。

## Windows

下载 `Shiying-1.5-Windows-x64-Setup.exe`，双击安装，然后从开始菜单打开“拾影视频下载器”。安装到当前用户目录，不要求手动安装 Python、FFmpeg、Go 或配置 PATH。安装器包含程序、Python、下载工具、音视频处理工具和识别依赖。

默认程序目录：`%LOCALAPPDATA%\Programs\Shiying`。默认视频目录：`%USERPROFILE%\VideoExtract`，可在界面更改。模型和运行数据：`%LOCALAPPDATA%\Shiying`。卸载程序不会主动删除媒体库或用户模型。

Windows 包为 x64。Windows 11 ARM64 使用系统的 x64 兼容运行能力，必须以虚拟机实测为准，不能只根据架构设置判断兼容。

## macOS

下载 `Shiying-1.5-macOS-arm64.zip`，解压后将完整 App 拖入“应用程序”，再打开。面向 Apple Silicon；不是 Intel 通用包。不要拆开 App 内部文件。

运行环境放在 App 内，无需安装 Homebrew 或准备 `~/.vx`。默认媒体库为 `~/VideoExtract`，模型和数据保存在 `~/Library/Application Support/拾影`。开发机打包过程使用的工具不等于使用者需要配置的环境。

## 首次使用

先选“仅下载”，粘贴一个作品链接并开始。主页、推荐页不能当成单个作品链接。需要登录的平台可能仍需要浏览器登录态；这是网站访问条件，不属于运行环境安装。

选择转写时，语音模型首次使用联网自动下载，之后使用本地缓存。当前一体化包包含识别代码和依赖，但不是“所有模型都预置、首次完全离线”的版本。首次模型下载可能较大、较慢。

Mac 使用系统 Vision OCR、FunASR 和 parakeet-mlx。Windows 使用 RapidOCR、FunASR 和 faster-whisper；输出结果可能有所不同。

## 外部下载器

Mac 的 Downie 4、Windows 的 IDM 是可选商业软件，未包含它们的安装包或许可证。不安装它们也可以使用内核下载和本地视频处理。

Windows 选择 IDM 之前，需自行安装和授权 IDM。拾影先解析可用的单文件媒体地址，再交给 IDM；仅发送请求不算成功，必须等到有效视频并归档。若页面地址解析本身失败，IDM 不保证能够补救。取消拾影只停止拾影处理，IDM 下载可能继续。

视频号无分享链接采集仍是试验功能；需要页面桥接等条件，安装 App 本身不代表真实采集已通过。不会自动修改代理、系统证书或登录态。

## 签名与反馈

当前测试包未完成 Apple 公证或 Windows 发布者签名，系统可能提示无法验证发布者。只使用本仓库提供的产物并核对 SHA-256。反馈时提供系统版本、选择的模式和日志；不要公开 Cookie 或账户凭据。
