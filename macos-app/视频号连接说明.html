视频号采集：先连接，再选择作品

当前为试验功能。服务启动、链接取得和视频下载是三个不同结果；真实无链接卡片验收尚未完成。

  1. 在电脑版微信点击卡片，打开目标视频并播放片刻。
  2. 回拾影，打开“视频号采集”。点击“启动连接服务”，再“检查连接”。默认 API 端口为 2022；2023 是上游代理端口。
  3. 显示“页面已连接”后，点击“读取最近观看”，按作者和标题选择作品。记录可能来自页面缓存，请核对目标。
  4. 点击“获取链接并加入队列”，回主窗口点击“开始下载”。已有分享链接路径需要 Edge 或 Chrome 的元宝登录态。

显示“微信页面尚未接入”怎么办

本 App 启动的组件只提供本机 API，不开启系统代理、TUN，不安装或信任证书。它不能单靠启动服务读取微信页面。需要先完成与本机网络相容的页面接入，不能只填 objectId。

如使用上游完整采集代理，应先核对当前代理、证书以及退出恢复方案。不要在已有 Surge 等工具运行时直接覆盖系统代理。完成接入后使用其实际 API 端口检查连接；已有外部服务无需再点启动。

本 App 只停止自己启动的服务，不停止用户其他下载器。关闭采集窗口不会停服务；“停止本窗口服务”或退出拾影会停止本 App 启动的 API 服务。

已经下载到视频文件

可在主窗口“添加本地视频”导入。仅有视频文件不能证明分享链接已经提取成功；本地导入不会猜测作品作者或发布日期。
